How RepoChat GraphRAG Works

Traditional search relies solely on vector similarity (semantic embeddings). RepoChat augments vectors with static Abstract Syntax Tree (AST) call graphs. When you ask a question:

  1. Top Vector Hits are retrieved from pgvector based on embedding cosine similarity.
  2. Call Graph Neighborhoods (callers and callees) are traversed to capture architectural context.
  3. Citation Validation strictly ensures citations like [Service.java:10-40] point to existing files and line ranges.
